# Google Phone 244.0.1001930441 — decompiled code

This repository contains a JADX source export from the five DEX files in the arm64 APK for Google Phone 244.0.1001930441. Decompiled Java files are under [`decompiled/`](decompiled/), grouped by their original DEX file (`classes` through `classes5`). The export contains 30,265 `.java` files. The APK and raw DEX files are not included.

The export was produced with JADX 1.5.6, processing each DEX separately with `--no-res --no-imports` to fit the available memory. JADX reported per-class decompilation errors (161, 186, and 91 for the first three DEX files; 8 for classes4; none for classes5) while still producing source output. A source file can therefore contain incomplete code or fallback output. This is a decompiler reconstruction, not original Google source code.
